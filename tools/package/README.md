# Math 10-3 Course Package

A complete Alberta Math 10-3 course, ready to set up for your own classes:

- **Class website**: practice for every lesson (new numbers every time, hints, the TI-30XIIS calculator built in), a guided
  project in every unit, unit tests and exit slips written on the site, certification cards for each outcome, and a class calendar.
- **Lesson pages** to project and write on with an Apple Pencil, with animated explainers, warm-ups and Stand Up Breaks.
  Your notes are shared live with each class.
- **Teacher Ledger**: class lists, live view, progress, outcomes, tests, exit slips, retests, projects, the calendar,
  PowerSchool export and emails home.
- **Booklets** for all 7 units (65 lessons): notes, assignments, extra practice and full solutions, as PDFs and LaTeX.

Start with **INSTALL.md**: it walks through the setup step by step, in about an hour.
