Geometry toolkit (Units 5–7)

Every piece of js/geo.js: a protractor to drag and turn, angle drawings, the numbered transversal, a compass rose for bearings, animated compass-and-straightedge constructions, and tangram and pentomino pieces. Units 6–7 add similar figures, a grid to draw enlargements on, bar scales and a map tape, right triangles with opp/adj/hyp, the Pythagoras squares and proof, nested similar right triangles, angles of elevation and depression, a clinometer, shadows and mirrors (sections 9–16). The reference for builders is lessons/BLOCKS.md (Geometry toolkit).

1

Protractor (drag it, turn it)

Drag the protractor to move it; turn it with the round handles. Geo.protractor(host, { angle: { a1, a2, names } }). Try Which scale?, Hide the reading, New angle, Show me.

2

Angle drawings

Geo.angle(svg, { vertex, a1, a2, label, reflex, names, fill }) — directions in math degrees (0 = right, counterclockwise).

3

Transversals

Geo.transversal(host, { parallel, tilt, angles, highlight, marks }). Angles 1–4 at the top crossing and 5–8 at the bottom, each clockwise from the upper-left.

7

Tangram

Drag a piece; tap to turn it 45°; double-tap to flip it. Pieces snap to each other's corners. Geo.tangram(host, { labels: 'area' })

8

Pentominoes

Tap to turn 90°, double-tap to flip; pieces snap to the grid. Fill the dashed 5 × 3 rectangle with I, P and P. Geo.pentomino(host, { letters: 'IPP', board: { cols: 5, rows: 3 } })

All twelve: Geo.pentomino(host, { height: 470 })

9

Similar figures (Unit 6)

Geo.similar(host, { shape: 'trap', k: 1.5, names: ['ABCD', 'PQRS'], units: 'cm', ratios: true }) — matching sides in the same colour, k = new ÷ original. Projection from a point: mode: 'centre'.

10

Draw an enlargement on a grid

Tap grid points; tap the first corner to close; Check compares with k. Geo.gridDraw(host, { shape: 'L', k: 2, names: ['ABCDEF'] })

11

Bar scales and the map tape

Geo.scaleBar(host, { scale: '1 cm : 2 m' }) · Geo.mapTape(host, { scale: '1 cm : 5 km', places }) — drag the round ends.

12

Right triangles: opp, adj, hyp (Unit 7)

Geo.rightTri(host, { a: 3, b: 4, theta: 'A', sides: { a: '3', b: '4', c: '?' } }); squares on the sides: squares: 'grid'; the rearrangement proof: Geo.pythagProof.

13

Similar right triangles: the trig ratios

Move the slider: every triangle gives the same ratios. Geo.similarRights(host, { theta: 35, sizes: [3, 5, 7] })

14

Angles of elevation and depression

Geo.elevation(host, { kind: 'elevation', angle: 38, dist: 25, eye: 1.6, target: 'tree' }) · kind: 'depression', observer: 'lighthouse', target: 'boat', alt: true

15

Clinometer (drag to tilt)

The string always hangs straight down. Geo.clinometer(host, { angle: 30 }) (protractor scale: elevation = 90° − reading) or scale: 'direct'.

16

Shadows and mirrors

Geo.shadow(host, { small: { h: 1.8, shadow: 2.4 }, big: { shadow: 18, kind: 'tower', label: { h: 'h' } } }) · Geo.mirror(host, { eye: 1.6, d1: 2.1, d2: 12.5, labels: { h: 'h' } })
